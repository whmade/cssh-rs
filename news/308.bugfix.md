`Backspace` now erases the character before the cursor on the remote
session, whether typed with the daemon focused or in a client window.
It sends `^?` (0x7f), the erase character remote terminals expect and
what xterm and Windows Terminal send, instead of `^H`. The `Delete`
key is unchanged and still sends `ESC [3~`.
Keys typed in a client window now keep the `Ctrl`, `Shift` and `Alt`
held with them, as keys typed with the daemon focused already did:
`Alt + x` now sends `ESC x` instead of `x`, and `Ctrl + Left` sends
`ESC [1;5D` instead of a plain `Left`. `Ctrl + Backspace` and
`Shift + Tab` now send what Windows Terminal sends: `^H` instead of
`^?`, and `ESC [Z` instead of a plain tab. `Ctrl + Tab`,
`Ctrl + Shift + Tab`, `Ctrl + Shift + Enter` and
`Ctrl + Shift + Backspace`, which sent nothing, now send a tab,
`ESC [Z`, LF and `^H`, as Windows Terminal does.
