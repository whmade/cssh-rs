Pressing `Ctrl + Break` while the daemon is focused no longer closes the
daemon and with it every client window. On Windows 11 it now ends the
`ssh` session of each enabled client, as it ends a single client's
session when pressed in that client's window. On Windows 10, whose
console host predates the keyboard input mode this relies on,
`Ctrl + Break` reaches `ssh` neither from the daemon nor from a client
window.
