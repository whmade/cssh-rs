Ctrl and Shift held with an arrow key, Home, End, Page Up, Page Down,
Insert, Delete or F1 to F12 while the daemon is focused now reach the
remote sessions, so `Ctrl + Left` and `Ctrl + Right` move by word in
readline. Previously the clients sent these keys as if Ctrl and Shift
were not held. They now send the xterm sequences, such as `ESC [1;5D`
for `Ctrl + Left` and `ESC [15;2~` for `Shift + F5`. Alt held with
these keys now goes into the same sequence, `ESC [1;3D` for
`Alt + Left`, instead of an ESC before the plain key.
